# Brewly ️
Сообщество ценителей кофе. Платформа для обмена рецептами с умной системой фильтрации по вкусовому профилю.

##  Функционал
- **CRUD рецептов:** Создание, редактирование, удаление, просмотр.
- **Умный поиск:** Фильтрация по категориям и вкусовым параметрам (кислотность, горечь, сладость, тело).
- **Личный кабинет:** Профиль пользователя, загрузка аватара, список своих рецептов.
- **Избранное:** Возможность сохранять любимые рецепты.
- **Безопасность:** CSRF-защита, валидация форм, разграничение прав доступа.

##  Технологии
- PHP 7.4+ / 8.x
- Yii2 Framework 2.0
- MySQL / MariaDB
- HTML5, CSS3, JavaScript

##  Установка и запуск
1. Клонируйте репозиторий:
   `git clone https://github.com/your-username/brewly.git`
2. Перейдите в папку:
   `cd brewly`
3. Установите зависимости (если есть composer):
   `composer install`
4. Настройте базу данных в файле `config/db.php`.
5. Примените миграции:
   `php yii migrate`
6. Запустите встроенный сервер:
   `php yii serve`
7. Откройте в браузере: `http://localhost:8080`

##  Структура БД
Основные таблицы: `user`, `recipe`, `category`, `favorite`.
Связи между таблицами позволяют реализовать функционал избранных рецептов и авторство.
